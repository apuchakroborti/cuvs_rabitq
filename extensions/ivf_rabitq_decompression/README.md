# IVF-RaBitQ decompression extension

This additive extension reconstructs approximate vectors from indexes written by
`cuvs::neighbors::ivf_rabitq::serialize` without modifying the author-provided IVF-RaBitQ code.

The loader parses the serialized index, uploads its packed short/extended codes, factors, rotated
centroids, rotation matrix, list membership, and original IDs, and then performs:

1. packed-code decode and rotated-centroid restoration;
2. inverse dense rotation using the stored orthogonal matrix;
3. padding removal and scatter back to original vector-ID order.

The reconstruction scale follows the factors generated by the IVF quantizer:
`residual_hat = (-0.5 * f_rescale) * signed_code`. For one-bit indexes the signed code is
`{-0.5, +0.5}`; extended indexes recover the signed magnitude from the long-code stream.

Reported decompression time is GPU-kernel only. Index file reading, compressed-data H2D upload,
reconstructed-data D2H transfer, MSE, and file output are excluded.
